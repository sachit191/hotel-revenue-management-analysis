Hotel Revenue Management & Demand Analysis

Project Status: In Progress
Tools: Microsoft Excel, Data Analysis, Data Visualisation

Project Overview

This project analyses hotel booking data to understand booking patterns, cancellation trends, seasonal demand and pricing behaviour. The objective is to explore how data analytics can support hotel revenue management and business decision-making.

Dataset

119,390 hotel booking records

City Hotel and Resort Hotel

Booking, customer, pricing and cancellation information

Historical data covering 2015–2017

Key Areas of Analysis

Hotel booking and cancellation trends

Average Daily Rate (ADR) analysis

Monthly demand patterns

Distribution channel analysis

Comparison between City Hotel and Resort Hotel

Project Deliverable

An Excel workbook containing data analysis, summary metrics and dashboard-based insights.

Objective

To understand how historical booking data can help identify demand patterns and support better pricing and revenue management decisions.

Note: This is an academic portfolio project using historical data. Findings are analytical estimates and do not represent actual hotel financial statements.
